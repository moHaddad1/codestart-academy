CSS Layout

CSS layout properties allow you to control the positioning and sizing of elements on a webpage to create a structured, responsive design.

CSS Layout — The Basics

CSS layout properties allow you to control the positioning and sizing of elements on a webpage to create a structured design.

  • Display: Defines how an element is rendered (block, inline, flex).
  • Flexbox: Best for one-dimensional layouts (rows or columns).
  • Positioning: Allows you to place elements using top, bottom, left, and right.

The Display Property

The display property is the most important CSS property for controlling layout.

Value Description
block Starts on a new line and takes up full width.
inline Does not start on a new line, takes only width needed.
flex Enables a flexbox layout for child elements.

Interactive Flexbox Example

Flexbox is used to align items easily in a container. Click any justify-content value below to see how the items distribute horizontally:

justify-content Controls 
.container {
  display: flex;
  justify-content: space-around;
}
