HTML Elements

An HTML element is the basic building block of a webpage. Each element is written using tags that describe the meaning and display of content.

1. Headings

Headings are used for titles and section hierarchy, ranging from <h1> (most important) to <h6>:

<h1>This is h1</h1>
<h2>This is h2</h2>
<h3>This is h3</h3>

2. Paragraph

Paragraph elements (<p>) organize blocks of text and automatically add spacing between paragraphs:

<p>This is a simple paragraph.</p>
<p>This is another paragraph to show how the text appears on the page.</p>

3. Links

Links are used to move between pages using the anchor tag <a> and its href attribute:

<a href="https://www.google.com" target="_blank">Visit Google</a>
Live Preview

4. Line Break

Use the empty <br> element when you need a single line break without starting a new paragraph:

<p>
  This is line one<br>
  This is line two<br>
  This is line three
</p>

5. Multiple Elements Together

You can combine different elements in one section — such as text, links, line breaks, and clickable buttons:

<p>
  You can combine different elements in one section like this:<br>
  <a href="#combined-demo">Simple Link</a><br>
  <button type="button">Simple Button</button>
</p>
