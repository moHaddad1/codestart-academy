CSS Box Model

The CSS box model describes how elements are displayed on a web page. Every element is treated as a rectangular box consisting of content, padding, border, and margin.

Box Model Components

The box model is made up of four main parts, from the inside out:

  • Content: The actual text or image inside the element.
  • Padding: Space between the content and the border.
  • Border: A line surrounding the padding.
  • Margin: Space outside the border separating the element from neighbors.

How Size is Calculated

Under the default box-sizing: content-box model, the total space occupied by an element combines every layer of the box model:

Property Formula
Total Width Content + Left/Right Padding + Left/Right Border + Left/Right Margin
Total Height Content + Top/Bottom Padding + Top/Bottom Border + Top/Bottom Margin

Pro Tip: Most modern stylesheets set * { box-sizing: border-box; } so that padding and border stay inside your declared width, making responsive layouts far more predictable. Try toggling border-box in the visualizer above to see the difference!

Example Code

Here is a standard CSS rule applying width, padding, border, and margin to a <div> element:

div {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  margin: 30px;
}
