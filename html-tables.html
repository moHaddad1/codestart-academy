HTML Tables

HTML tables let you display data in rows and columns, kind of like a spreadsheet inside your webpage.

Define an HTML Table

A table is made of rows, and each row has cells inside it. You use different tags for headers vs regular data cells.

Example 
<table>
  <tr>
    <th>Company</th>
    <th>Contact</th>
    <th>Country</th>
  </tr>
  <tr>
    <td>Alfreds Futterkiste</td>
    <td>Maria Anders</td>
    <td>Germany</td>
  </tr>
</table>
Try it Yourself »

Table Cells

Each cell in a table is wrapped in a <td> tag. The "td" stands for table data.

Basically anything you put between <td> and </td> shows up as one cell.

Example 
<table>
  <tr>
    <td>Emil</td>
    <td>Tobias</td>
    <td>Linus</td>
  </tr>
</table>
Try it Yourself »

Note: You can put almost anything inside a table cell — text, images, links, even another table.

Table Rows

Rows are made with the <tr> tag — "tr" = table row. Each row wraps around the cells that belong to it.

Example 
<table>
  <tr>
    <td>Emil</td>
    <td>Tobias</td>
    <td>Linus</td>
  </tr>
  <tr>
    <td>16</td>
    <td>14</td>
    <td>10</td>
  </tr>
</table>
Try it Yourself »

Note: There are cases where rows have different numbers of cells (using colspan/rowspan), which you can use for complex layouts.

Table Headers

To make a cell a header cell, use <th> instead of <td>. "th" stands for table header.

Browsers automatically make <th> text bold and centered.

Example 
<table>
  <tr>
    <th>Person 1</th>
    <th>Person 2</th>
    <th>Person 3</th>
  </tr>
</table>
Try it Yourself »

HTML Table Tags

Tag Description
<table>Defines a table
<th>Defines a header cell in a table
<tr>Defines a row in a table
<td>Defines a cell in a table
<caption>Adds a title/caption above the table
<colgroup>Used to group columns so you can style them together
<col>Goes inside colgroup, targets a specific column
<thead>Wraps the header rows of the table
<tbody>Wraps the main body rows of the table
<tfoot>Wraps the footer rows of the table

For a full list of HTML tags check out the HTML Tag Reference on W3Schools.
