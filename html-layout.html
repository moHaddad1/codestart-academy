HTML Layout

Organize your webpage cleanly using block containers and semantic HTML5 landmarks so both browsers and screen readers understand your page structure.

The div Element <div>

The <div> element is a block-level container used to group HTML elements together so you can style or manipulate them with CSS or JavaScript.

  • It starts on a new line.
  • Can contain other block display elements such as paragraphs, unordered lists, and even other <div> elements.
Example 
<div>
  <p>This is inside the div</p>
  <p>This text is centered because it is inside the div.</p>
</div>

<p>This is another paragraph outside the div.</p>

HTML5 Structural Elements

HTML5 introduced specific elements to define the structure of a web page clearly.

  • <header>: Contains the web page document's headings and introductory content.
  • <nav>: Contains the web page document's main navigation.
  • <main>: Contains the main content of a web page document. There should be only one <main> element per web page.
  • <footer>: Contains the web page document's footer information.
Example Structure 
<body>

  <header>document headings go here</header>

  <nav>main navigation goes here</nav>

  <main>main content goes here</main>

  <footer>document footer information goes here</footer>

</body>
<body>
<header> — Site branding & title
<nav> — Primary navigation links
<main>
Unique page content, articles & sections
</main>
<footer> — Copyright & helpful links
</body>

Accessibility Tip: Prefer semantic elements like <header>, <nav>, <main>, and <footer> over generic <div> tags whenever describing page landmarks.
