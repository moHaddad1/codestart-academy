CSS Selectors

Selectors define which HTML elements a CSS rule applies to. Master the four most common selector types used in everyday stylesheets.

1. HTML Element Name Selector

This targets all instances of a specific HTML tag across the document.

p {
  color: blue;
}

2. Class Selector

Used to apply a style to one or more elements. Configure with a dot (.).

.new {
  color: red;
  font-style: italic;
}

3. ID Selector

Used to apply a style to only one unique element. Configure with a hash (#).

#header-main {
  color: #FF0000;
  font-size: 2em;
}

4. Descendant Selector

Targets an element that is nested inside another element.

nav a {
  text-decoration: none;
}

Selector Quick Comparison

Selector Type Syntax Targets
Element p Every matching HTML tag on the page
Class .new All elements with class="new"
ID #header-main The single unique element with id="header-main"
Descendant nav a Any <a> element located inside a <nav>
