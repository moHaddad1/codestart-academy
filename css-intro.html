CSS Introduction

CSS is the language we use to style a web page — it controls things like colors, fonts, spacing, and layout across every screen size.

What is CSS?

CSS is the language we use to style a web page — it controls things like colors, fonts, spacing, and layout.

  • CSS stands for Cascading Style Sheets
  • CSS describes how HTML elements should be displayed on screen, paper, or other media
  • CSS saves a lot of work — one stylesheet can control the look of many pages at once
  • External stylesheets are saved in .css files and linked to your HTML

Why Use CSS?

CSS is used to define the style of your web pages — the design, layout, and how things look on different screen sizes and devices.

Example 
body {
  background-color: lightblue;
}

h1 {
  color: white;
  text-align: center;
}

p {
  font-family: verdana;
  font-size: 20px;
}
Try it Yourself »

CSS Saves a Lot of Work!

CSS rules are normally written in an external .css file that you link to your HTML pages.

The big advantage is that if you want to change the look of your whole website, you only have to edit one file instead of changing every single HTML page.

Tip: This is why keeping your CSS separate from your HTML is considered best practice — it makes your project way easier to manage.
