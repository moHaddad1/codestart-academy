HTML Basic Elements

HTML
Tag Description
<html> Considered the root element of any HTML document. Contains the head and body.
<head> Contains information necessary for the document's display (Title, Meta).
<h1> to <h6> Headings, from Level 1 (largest) down to Level 6.
<p> Groups sentences and sections of text together (Paragraph).
<br> A void element that causes the next element or text to display on a new line.
<ul> / <ol> Unordered List (bullet points) / Ordered List (numbers or letters).
<a href="..."> The anchor element, specifies a hyperlink reference to a file or URL.
<img src="..."> Configures graphics/images on a web page. Uses the alt attribute for alternate text.

HTML5 Layout, Tables & Forms

HTML
Tag Description
<div> Generic block-level container used to group elements for styling or scripting.
<header>, <nav>, <main>, <footer> Semantic HTML5 landmark elements that define page structure clearly.
<table>, <tr>, <th>, <td> Defines tabular data with rows (<tr>), header cells (<th>), and data cells (<td>).
<form>, <label>, <input> Collects user input via text fields, radio buttons, checkboxes, and submit buttons. Bind labels with for & id. 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  <main><h1>Hello World</h1></main>
</body>
</html>

CSS Text Properties

CSS
Property Common Values / Description
text-align left, right, center, justify, start, end
font-weight bold, lighter, 100 to 900
text-decoration underline, overline, line-through, none
text-decoration-style solid, double, dotted, dashed, wavy
line-height Sets the height between two lines (e.g., normal, 1.5, 2.5)
letter-spacing Controls the horizontal space between letters (e.g., normal, 10px)
font-family Specifies a prioritized list of font family names (e.g., Arial, sans-serif)

CSS Box Model, Layout & Selectors

CSS
Property / Selector Description
padding / border / margin Controls inner space around content, the border line, and outer space separating elements.
box-sizing content-box (default) or border-box (includes padding and border within width).
display Controls rendering behavior: block, inline, inline-block, flex, grid.
justify-content Aligns flex items along the main axis: flex-start, center, space-between, space-around.
p, .class, #id, nav a Targets elements by tag name, reusable class (.), unique ID (#), or descendant hierarchy. 
* {
  box-sizing: border-box;
}

.flex-container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}
